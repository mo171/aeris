# Frontend Memory

The handover log lives in **[`fcontext/memory.md`](./fcontext/memory.md)** — read that at the start of
every session. It is kept in one place so there is never a question of which copy is current.

Quick orientation for a cold start:

- `fcontext/architecture-context.md` — stack, boundaries, data philosophy, invariants
- `fcontext/folder-archtecture.md` — folder responsibilities and dependency rules
- `fcontext/code-standards.md` — conventions
- `fcontext/feature-spec/` — the specs each build was written against
- `fcontext/memory.md` — **what is actually built, what is verified, what is deferred, and the backend contract**

# SATQUERY AI — AERIS
## Agentic Earth Reasoning & Intelligence System

> An intelligent remote-sensing analysis platform that allows users to interact with satellite imagery through natural language and voice, automatically selects the appropriate AI models and geospatial tools, performs single-image, cross-modal, and temporal analysis, produces visual evidence, and turns every investigation into an auditable intelligence workflow.

---

# 1. THE CORE IDEA

AERIS transforms satellite imagery analysis from a collection of separate GIS/AI tools into one intelligent investigation system.

Instead of the user needing to know:

- which satellite dataset to use
- which sensor is appropriate
- whether an image is optical or SAR
- which AI model to run
- how to perform change detection
- how to create a spatial mask
- how to compare two observations
- how to interpret the result

the user simply asks:

> "What changed in this area between these two dates?"

or:

> "Find all major built-up regions."

or:

> "Use the optical and SAR imagery together to identify water-covered areas."

AERIS understands the request, inspects the available imagery, creates an execution plan, selects the appropriate specialist models/tools, executes them, validates the results, generates visual evidence, and explains the result.
